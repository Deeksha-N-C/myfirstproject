Tech Glossary

HTML
HTML (HyperText Markup Language) is used to create the structure of a web page. It defines elements such as headings, paragraphs, images, links, tables, forms, and buttons using tags. HTML tells the browser what content should appear on the webpage.
CSS
CSS (Cascading Style Sheets) is used to style and design web pages. It controls properties such as colors, fonts, spacing, borders, sizes, layouts, and responsiveness. CSS works together with HTML to make a webpage visually attractive and well-organized.
JavaScript
JavaScript (JS) is a programming language used to add behavior and interactivity to web pages. It can respond to user actions such as clicks, typing, and form submissions, and it can dynamically change HTML and CSS. JavaScript is also used for frontend and backend development.
Java
Java is a general-purpose, object-oriented programming language used to develop applications such as web applications, enterprise software, desktop applications, and Android applications. Java is known for platform independence, meaning Java code can run on different systems through the Java Virtual Machine (JVM).
Python
Python is a high-level, general-purpose programming language known for its simple and readable syntax. It is widely used in web development, data science, machine learning, automation, scripting, and artificial intelligence. Python allows developers to write programs with relatively less code.
